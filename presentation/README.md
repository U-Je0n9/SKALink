# SKALog 발표자료

## 산출물

- `SKALog_발표자료.pptx`: 편집 가능한 최종 발표자료, 16:9, 22쪽
- `build_skalog_ppt.js`: PPTX 재생성 소스
- `assets/`: 원본 `SKALog.pptx`에서 추출해 재사용한 서비스 화면 캡처

## 발표 흐름

1. 기획 배경과 Pain Point
2. 사용자 역할과 역할별 핵심 화면
3. 질문·보충 설명·학습자료·버전 관리 흐름
4. 데이터 모델과 OAS 기반 API 설계
5. 실제 운영을 위한 개선 로드맵

## 디자인 원칙

- 디자인 레퍼런스의 컨설팅형 구성, 좌측 세로 인덱스, 얇은 구분선, 넓은 여백을 반영
- SKALog 서비스와 같은 딥 그린을 주색으로 사용하고 라임·오렌지는 강조에만 제한
- 전체 글꼴은 Pretendard로 지정
- 본문은 대부분 12pt 이상, 핵심 설명은 13–18pt, 제목은 27pt 이상으로 구성
- 화면 슬라이드는 실제 캡처를 주인공으로 두고 2–4개의 설명만 배치

## 재생성

프로젝트 의존성이 설치된 상태에서 저장소 루트에서 실행합니다.

```bash
node presentation/build_skalog_ppt.js
```
