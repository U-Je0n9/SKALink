# Learnary — SKALA 학습 지식 공유 플랫폼

프론트엔드 초안입니다. 별도 패키지 설치 없이 Node.js만으로 실행됩니다.

```bash
cd projects
npm run dev
```

브라우저에서 `http://localhost:4173`을 엽니다.

## 데모 계정

- 교육생 1반: `student1` / `1234`
- 교육생 4반: `student4` / `1234`
- 교수자: `professor` / `1234`
- 관리자: `admin` / `1234`

질문 등록, 답변 등록, 질문 해결/재개, 자료 버전 확인 상태는 목 API 서비스(`mockApi.js`)를 통해 `localStorage`에 보존됩니다. 유사 질문은 동일 과목의 제목 단어를 비교하는 데모 방식이며 실제 의미 검색이나 AI 호출이 아닙니다. 인증 역시 발표용 세션 모의로, 실제 보안을 제공하지 않습니다.

현재 초안은 로그인, 과목 대시보드, 과목별 Q&A/설명/자료 탭, 질문 상세·작성, 설명 및 자료 상세 흐름에 집중했습니다. 관리자 운영 CRUD, 파일 Blob 영구 저장, 실제 다운로드, OpenAPI/DBML 최종본은 다음 구현 단계 대상입니다.
