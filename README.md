# Learnary — SKALA 학습 지식 공유 플랫폼

수업이 끝난 뒤에도 10개 반의 질문·답변, 교수님 보충 설명과 버전별 학습자료를 함께 찾고 이어서 학습하는 프론트엔드 중심 데모입니다.

## 실행

Node.js 20 이상이 필요합니다.

```bash
cd projects
npm install
npm run dev
```

- 서비스: <http://localhost:4173>
- Swagger UI: <http://localhost:4173/swagger>
- OpenAPI YML: <http://localhost:4173/SKALA_학습지식공유-API.yml>
- OAS Mock API: <http://localhost:4173/api>

4173 포트가 사용 중이면 `PORT=4174 npm run dev`처럼 실행할 수 있습니다.

## 데모 계정

모든 데모 계정 비밀번호는 `1234`입니다.

| 역할 | 계정 | 설명 |

자동 승인 회원가입은 아직 가입되지 않은 `P308 / 정나래 / 8반 / narae@skala.example` 명단으로 확인할 수 있습니다. 정보 중 하나라도 다르면 `PENDING`으로 등록되고 관리자 승인이 필요합니다.

## 구현 범위

### 교육생

- 자기 층 수업 일정이 있는 과목과 개인화된 예정·진행·종료 상태 조회
- 과목 검색·상태 필터, 전체 반 공유 질문·답변과 유사 질문 데모 추천
- 공개 범위에 따른 설명·자료 자동 필터 및 자기 반 실습 교수님 표시
- 메인 상단 신규 자료의 개인별 읽음 처리와 `−` 숨김
- 다중 파일 자료, 이전 버전, 변경 설명과 최신 버전 확인

### 교수님

- 내 담당 과목 우선 표시와 담당/전체 미답변 질문 전환
- 담당 여부와 관계없이 질문 답변
- 배정 과목에 설명·자료 등록 및 `전체 / 담당 층 / 담당 반` 공개 범위 선택
- 본인 자료에 다중 파일 새 버전 등록, 기존 버전 보존과 충돌 방지

### 관리자

- 교육생 가입 승인·반려 및 활성 상태 변경, 사전 SKALA 명단 조회
- 시간표를 확인해 과목 등록·수정과 층별 수업 기간 설정
- 전임·실습 교수님 및 담당 층·반 배정

`data/★ 판교캠퍼스_4기 반별 시간표(0805)_F.xlsx`를 기준으로 4층 1~5반, 5층 6~10반과 2026년 9월 수업·교수 배정을 반영했습니다. 흰 배경의 굵은 이름은 전임 교수님(`LEAD`), 색 배경 이름은 실습 교수님(`PRACTICE`)으로 해석합니다.

`data/보충자료 예시.txt`의 「LLM과 비전 모델은 어떻게 다를까?」 전체 본문과 Agile/MSA 교재·가이드·소스·인프라 이미지 8개 파일 묶음도 포함했습니다.

## API와 Swagger

[SKALA_학습지식공유-API.yml](./SKALA_학습지식공유-API.yml)은 OpenAPI 3.0.3 기준이며 인증·회원가입, 과목·검색, 질문·답변, 설명·자료·버전, 개인 읽음·숨김, 관리자 회원·명단·과목·배정·콘텐츠 관리 계약을 모두 포함합니다.

총 30개 경로, 38개 API 작업, 45개 재사용 스키마이며 문법, 경로 매개변수와 모든 `$ref`를 검증했습니다. Swagger UI 자산은 `swagger-ui-dist`에서 로컬로 제공하므로 CDN이 필요하지 않습니다.

`npm run dev`는 정적 웹 서버와 Prism을 함께 실행합니다. Swagger의 `Try it out` 요청은 같은 출처의 `/api`를 거쳐 **OAS YML에서 자동 생성된 목 응답**을 받습니다. 과제 평가 범위에 맞춰 Security Scheme은 명세에서 제외했습니다. 브라우저 화면의 조작 상태는 별도로 [mockApi.js](./mockApi.js)의 `localStorage`에 보존되며, Prism 목 응답은 상태를 영구 저장하지 않습니다.

## 목 구현의 한계

- Prism은 OAS 계약 확인용 무상태 목 서버이므로 로그인 세션과 등록 결과를 영구 저장하지 않습니다.
- 실제 파일 Blob 대신 파일 메타데이터를 저장합니다.
- 유사 질문은 제목 단어 비교 데모이며 실제 의미 검색이나 AI 호출이 아닙니다.
- XLSX 자동 동기화 대신 분석한 초기 배정과 관리자 수정을 사용합니다.
- 운영 구현에는 서버 세션, 비밀번호 해시, 이메일 소유 확인, 트랜잭션 파일 저장, 접근 제어와 감사 로그가 필요합니다.
